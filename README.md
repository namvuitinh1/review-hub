# Review Hub

Web nhận xét video theo timecode cho khách: GitHub Pages + Google Drive + Google Sheet (Apps Script).

- `index.html`: trang khách (`?p=MÃ_DỰ_ÁN`)
- `admin.html`: trang quản lý (mật khẩu)
- `config.js`: điền `API_URL` và `DRIVE_API_KEY`; để trống thì chạy chế độ demo
- `apps-script/Code.gs`: backend, dán vào Apps Script của Google Sheet
- `demo/`: video mẫu cho chế độ demo (có thể xoá khi chạy thật)
